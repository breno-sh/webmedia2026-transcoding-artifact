# Reproducibility Artifact

Companion artifact for the WebMedia 2026 paper **"You Get What You Pay For—Except You Don't: Instance Families and Scaling Strategies for Cloud Video Transcoding"** by Breno Vasconcelos, Elisa de Fátima Andrade Soares, and Carlos Ferraz (Centro de Informática, Universidade Federal de Pernambuco — UFPE).

This repository contains the scripts, intermediate results, and processed datasets needed to reproduce every table, figure, and statistical claim in the paper. Raw per-run logs (≈9 GB of CPU-verification logs, FFmpeg traces, and pipeline timing dumps) are not bundled here for space reasons; the scripts below regenerate them from AWS EC2.

> **Reproduction placeholders.** Deployment-specific values — key-pair names, security-group names, and local file paths — appear as `<aws-key-pair-name>`, `<aws-security-group-name>`, and `./` placeholders. Substitute your own AWS values before re-running.

## 3. Reproduction

### 3.1 Quick path — re-derive tables from the bundled processed data
The processed CSVs/JSONs in `processed_data/` are the canonical source for every numerical claim in the paper. To regenerate the LaTeX rows for Tables 2–6:

```bash
python3 -m pip install -r requirements.txt    # pandas, numpy, scipy, matplotlib
python3 analysis/run_phase2_stats.py          # rebuilds Table 2 rows + Figure 1
python3 analysis/run_phase3_stats_all.py      # rebuilds Tables 3/4 rows + Figure 2
python3 analysis/generate_latex_rows.py       # emits LaTeX-ready table rows
```

### 3.2 Full path — re-run every experiment on AWS
Set your AWS credentials, key pair, and security group, then:

```bash
# Phase 1 — CPU homogeneity (100 launches per instance × 6 AZs, ~$15)
python3 phase1_homogeneity/detect_cpu_homogeneity.py

# Phase 2 — raw FFmpeg benchmarks (15 instances × 3 codecs × 4 threads × n=30, ~$50–80)
python3 phase2_benchmarks/all_instances_phase2_extended.py
python3 phase2_benchmarks/run_16_threads.py     # large instances only

# Phase 3 — CPU-verified scaling rerun (8 anchors × 30 runs, ~$100–150)
python3 phase3_scaling/rerun_cpu_verified.py

# Phase 4 — chunk-size sensitivity at 240p/720p/1080p (~$40–60)
python3 phase4_chunk_resolution/chunk_sensitivity_multiresolution.py
```

Estimated total reproduction cost (us-east-1 on-demand pricing, March 2026): **$400–600**. Total wall-clock time end-to-end: **4–6 days**.

## 4. Configuration to edit before running

Every experiment script reads an `AWS_CONFIG` (or `CONFIG`) dictionary at the top of the file. The placeholders you must replace are:

- `local_key_path` → path to your `.pem` SSH key
- `key_name` → AWS key-pair name in the target region
- `security_groups` → an existing SG that allows inbound SSH (port 22)
- `ami_id` (Phase 1, 3.1) → any Ubuntu 22.04 LTS AMI
- `ami_id` (Phase 3.2) → the *custom* pre-baked AMI (script `experiment_runners/phase3_master/create_custom_ami.py` builds it). For ARM workloads, also see `prereq_1_create_arm_ami.py`.

## 5. Software dependencies

- Python 3.8+
- `boto3 >= 1.28`, `paramiko >= 3.0`, `pandas >= 2.0`, `numpy`, `scipy`, `matplotlib`
- AWS CLI configured with EC2 permissions: `RunInstances`, `TerminateInstances`, `DescribeInstances`, `CreateImage`, `DescribeImages` for both `us-east-1` and `sa-east-1`
- Docker (for containerized FFmpeg in Phase 2)

## 6. Data provenance

- **Phase 2 aggregated CSVs** (`processed_data/experimental_data/aggregated_*.csv`): one row per (instance × codec × thread-count), with median / std / min / max compression time, efficiency, and per-operation cost.
- **`averages_n30.csv`** (Phase 3 / 4 canonical source): one row per `<instance>_<strategy>_<phase>` configuration, with `n=30` measurements decomposed into total wall-clock, setup time, and pure encoding time. This is the file that backs every Phase-3 number in the paper (verified against `analysis/run_phase3_stats_all.py`).
- **`m2_results_sa_east_1.csv`**: regional replication, three representative instances (`t3.micro`, `m5.large`, `c5.large`), H.264 horizontal, n=30.
- **`statistical_tests_{c5,m5}.csv`**: pairwise Welch's t-test, Mann–Whitney U, and Cohen's d values computed for the statistical analysis (§4.2.4, §4.3.3).

## 7. Known limitations of this snapshot

- Raw per-run FFmpeg logs (≈9 GB) are not bundled; regenerated by the scripts above.
- The custom AMI ID in the scripts (`ami-06c7c20c67513469a`) is private to the original AWS account. Re-build a local equivalent with `experiment_runners/phase3_master/create_custom_ami.py` before reproducing Phase 3.2.
- All experiments target `us-east-1` (primary) and `sa-east-1` (replication). Other regions are not represented.
